# macOS App Bundle with desktop-notifier

## Goal

Bundle aws-sso-monitor as a signed macOS `.app` with a `.pkg` installer, replacing the alerter CLI with the desktop-notifier library for native notifications.

## Decisions

- **Notifications:** Use `DesktopNotifierSync` from desktop-notifier. Action button "Open SSO" with `on_pressed` callback that opens the SSO URL. Notification grouping via `thread` parameter. No per-notification icon (macOS always shows the app bundle icon).
- **Bundler:** py2app, configured via `setup.py`. `LSUIElement: True` (no Dock icon). `argv_emulation: False`. Bundle identifier `systems.intelligible.aws-sso-monitor`.
- **App icon:** Sad AWS face (full-colour, frown arrow) as `.icns`. Generated by `scripts/generate_icons.py` using `iconutil`.
- **Signing:** `sudo codesign --sign "metr-santa-cert"`.
- **Packaging:** `.pkg` via `pkgbuild` that installs `.app` to `/Applications` and launchd plist to `~/Library/LaunchAgents/`.
- **Build script:** Single `scripts/build.sh` that generates icons, runs py2app, signs, and builds `.pkg`.
- **Bundle check:** Fail fast at startup if not running as a bundled app (`NSBundle.mainBundle.bundleIdentifier is None`).

## Changes

### `app.py`

- Replace `_send_notification` — use `DesktopNotifierSync.send()` with `Button("Open SSO", on_pressed=...)`, `sound=DEFAULT_SOUND`, `thread=notif.group`.
- Remove `threading` and `subprocess` imports.
- Remove alerter startup check (`shutil.which`). Replace with bundle identifier check.
- Create module-level `DesktopNotifierSync` instance.

### `icon.py`

- Remove `NOTIFICATION_ICON_SAD` (no longer needed — app bundle icon serves as notification icon).

### `notifications.py`

- No changes. `group` field maps to desktop-notifier's `thread` parameter.

### `generate_icons.py`

- Add `.icns` generation: render sad AWS face SVG at all required sizes (16–1024), write to `build/icon.icns` via `iconutil`.

### `setup.py` (new)

- py2app configuration: entry point, plist keys (`LSUIElement`, `CFBundleIdentifier`, etc.), `argv_emulation: False`, `includes: ["Foundation"]`.

### `scripts/build.sh` (new)

1. `uv run scripts/generate_icons.py`
2. `uv run python setup.py py2app`
3. `sudo codesign --sign "metr-santa-cert" --force --deep "build/dist/AWS SSO Monitor.app"`
4. `pkgbuild` — `.app` → `/Applications`, plist → `~/Library/LaunchAgents/`
5. Output: `build/AWS SSO Monitor.pkg`

### `pyproject.toml`

- Add `desktop-notifier` as runtime dependency.
- Add `py2app` as dev dependency.

### `.gitignore`

- Add `build/`.

### `systems.intelligible.aws-sso-monitor.plist`

- Update `ProgramArguments` to launch `/Applications/AWS SSO Monitor.app` via `open`.

### Resources
